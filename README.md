# Лабораторная работа #3
## Репозиторий данных 
### Описание
Данная работа направлена на реализацию приватного статического списка зарегистрированных пользователей, метода для регистрации пользователей, метода для авторизации пользователей, регистрации пользователей через окно «Регистрация», вывода уведомлений об ошибках

### Необходимые условия
Приложение Visual Studio 2022 с установленным компонентом C#

### Шаги установки
1. Установить последнюю версию репозитория
2. В проекте Lab3 открыть файл "Todo.sln"
3. Запустить проект
