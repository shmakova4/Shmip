# Лабораторная работа #1
## Контейнеры компоновки
### Описание
Данная работа направлена на создание макета будущего проекта, который будет выполнять функцию задачника. Цель: научиться создавать решение типа WpfApp, подключать решение к системе контроля версий, отправлять проект на свой удалённый репозиторий.

### Необходимые условия
Приложение Visual Studio 2022 с установленным компонентом C#

### Шаги установки
1. Установить последнюю версию репозитория
2. В проекте Lab1 открыть файл "Todo.sln"
3. Открыть обозреватель решений
4. Открыть окно MainWindow.xaml
5. Открыть окно Registration.xaml
