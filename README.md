# Лабораторная работа #1
## Контейнеры компоновки
Цель: научиться создавать решение типа WpfApp, подключать решение к системе контроля версий, отправлять проект на свой удалённый репозиторий.

### Необходимые условия
Приложение Visual Studio 

Шаги установки: 
1. Установить последнюю версию репозитория
2. В проекте Lab1 открыть файл "Todo.sln"
3. Собрать решение
4. Запустить проект

Описание:
Данный этап направлен на создание макета будущего проекта, который будет выполнять функцию задачника.
