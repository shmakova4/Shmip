# Лабораторная работа #2
## Элементы управления
### Описание
Данная работа направлена на реализацию с помощью классов проверки полей ввода, открытие окон согласно графу навигации. Поле ввода почты имеет проверку на корректность введенной почты, реализован переход между окнами

### Необходимые условия
Приложение Visual Studio 2022 с установленным компонентом C#

### Шаги установки
1. Установить последнюю версию репозитория
2. В проекте Lab2 открыть файл "Todo.sln"
3. Запустить проект
